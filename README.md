# GuessingApp

NUMBER-GUESSING APPLICATION:-
-----------------------------
   
   Develop a Number-Guessing Application that serves as a hands-on learning project to master core Java programming concepts. 
   This application helps learners understand how Java syntax, data types, control flow, functions, exception handling, 
   file handling, and database integration work together in a real-world, interactive console-based application.
   The project emphasizes problem-solving, user interaction, and incremental logic building while maintaining clean, 
   readable, and extensible code.
   
   USE CASE-1: GAME INITIALIZATION 
   
   
   Key Concepts: 
   ● Primitive Data Types 
   ● Random number generation 
   ● Constructor initialization 
   ● Encapsulation (private fields) 
   ● Constants (final keyword) 
   
   Key Requirements: 
   ● Generate a random target number within a predefined range
   ● Initialize maximum attempts 
   ● Initialize hint counter 
   ● Store game configuration 
   ● Display game welcome message and rules
   
   Key Benefits: 
   ● Controlled game setup 
   ● Reusable configuration logic 
   ● Predictable game behavior 
   ● Clear separation of initialization logic 
   ● Easy modification of difficulty levels 
   
   Goal: Initialize the guessing game with required configurations.

 USE CASE-2: USER GUESS SUBMISSION 
 
 Key Concepts: 
 
 ● Scanner input handling 
 ● Control flow (if-else, switch) 
 ● Looping (while, do-while)
 ● Method invocation
 ● Input validation
  
 Key Requirements:
 
  ● Accept user input 
  ● Validate numeric input 
  ● Compare guessed number with target 
  ● Track number of attempts 
  ● Provide feedback (higher/lower) 
  
  Key Benefits:
   ● Interactive user experience 
   ● Structured decision making
   ● Reduced runtime errors 
   ● Improved logical thinking 
   ● Clear user feedback loop
   
  Goal: Allow the player to submit a guess and receive immediate feedback.
